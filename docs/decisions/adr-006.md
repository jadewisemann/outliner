# ADR-006: 모바일 persistence 전략

- 상태: 확정
- 결정: 모바일 앱 패키징과 모바일 persistence는 Stage 3 이후로 분리하고, Stage 1 다중 문서 workspace와 Stage 2 데스크톱/계정/sync 제품화 이후에 진행한다.
- 이유: MVP의 핵심은 키보드 중심 웹 아웃라이너의 속도와 안정성이다.
- 영향: Stage 0~2는 웹 편집기, 다중 문서 제품 코어, 데스크톱/계정 기반 사용 흐름을 우선하며, 모바일에서는 IndexedDB 유지와 SQLite 전환을 Stage 3에서 별도 검증한다.
