# 문서

구현과 사용법은 저장소 루트의 [`.dev.md`](../.dev.md)가 기준이다. 이 폴더에는 재작성 이전에
정리해 둔 배경 문서만 남아 있다.

- [requirements](./requirements/index.md) — 제품 범위와 사용자 시나리오. 여전히 유효한 목표.
- [decisions](./decisions/index.md) — 과거 결정 기록. 일부는 재작성으로 뒤집혔다
  (Lexical 에디터, Yjs CRDT 동기화, 단일 문서 워크스페이스, 단계별 TDD 진행).

단계별 개발 계획과 테스트 스키마 문서는 제거했다. 코드가 작아져서 문서로 좌표를 잡을 필요가
없어졌기 때문이다. 새 결정이 생기면 `decisions/`에 한 파일로 남긴다.
