# 한 장 요약 — 무엇으로 만들었고, 왜 그렇게 골랐나

> 이 문서는 입구다. 규칙의 정본은 [DESIGN.md](../DESIGN.md), 결정 하나하나의 근거는 [docs/adr/](./adr/)에
> 있다. 여기에는 전체 그림과 "왜"의 요점만 둔다.

## 전체 그림

```
┌──────────────── 한 벌의 정적 빌드 (Vite + React 18 + TypeScript) ────────────────┐
│ 편집(행 = textarea) · 병합(merge.ts, 순수 함수) · 검증(validate.ts) · 질의 언어   │
└──────┬───────────────────┬───────────────────┬──────────────────┬───────────────┘
       │ 브라우저 탭         │ 설치된 PWA          │ 데스크톱 앱        │ Android 앱
       │                   │ (오프라인 셸 캐시)   │ Tauri 2 셸        │ Tauri 2 셸
       │                   │                    │ + 폴더 백엔드      │
       │                   │                    │ + 로컬 파일 사본    │ + 로컬 파일 사본
       └─────────┬─────────┴──────────┬─────────┴──────────┬───────┘
                 ▼                    ▼                    ▼
        GitHub 저장소          동기화 서비스 폴더       내 서버 / URL
        (문서당 파일, 커밋       (outliner.json 하나,    (Cloudflare Worker,
         = 버전 백업)            iCloud·Dropbox 등)      레퍼런스 서버, Firebase)
```

원격은 모두 선택이다. 켜지 않으면 각 기기에서 로컬로만 쓴다. 켜면 **병합은 언제나 기기에서** 일어나고,
원격은 바이트를 보관할 뿐이다.

## 선택과 그 이유

| 선택 | 이유 | 버린 대안 | 근거 |
|---|---|---|---|
| **병합을 클라이언트에** | GitHub·폴더·아무 서버가 모두 원격이 될 수 있고, 종단 간 암호화가 가능해진다 | 서버가 판정하는 동기화 | [ADR-0002](./adr/0002-client-side-merge.md) |
| **범용 CRDT 대신 필요한 셋만** (분수 정렬 키, 내용·위치 별도 스탬프, 묘비) | 아웃라인이 병합되는 데 필요한 것은 이 셋뿐이고, 기계 장치가 한 자릿수 작다 | Yjs·Automerge | [ADR-0003](./adr/0003-custom-merge-model.md) |
| **행마다 `<textarea>`, 서식은 마크다운 문자열** | 한글 IME가 브라우저 기본 동작 그대로 돈다. 내보내기에서 서식이 살아남는다 | contenteditable WYSIWYG | [editing.md](./design/editing.md) |
| **런타임 의존성 = react, react-dom, 지연 로드 katex** | 번들이 작고 성능이 예측 가능하다. 가상화·하이라이트·질의 언어를 직접 쓴다 | 에디터 프레임워크 | [ADR-0004](./adr/0004-katex-lazy-load.md) |
| **단축키는 표 하나 + 프리셋 둘** | 마크다운 에디터 관례와 Dynalist 관례는 같은 키를 다르게 쓴다. 표로 빼면 둘 다 고를 수 있고, 표는 기기 사이를 따라간다 | 하드코딩 | [ADR-0006](./adr/0006-keymap-presets.md), [0008](./adr/0008-keymap-travels.md) |
| **네이티브 앱은 Tauri 2** | 한 프로젝트로 macOS·Windows·Linux·Android. 시스템 웹뷰라 설치 파일이 수 MB다. 디스크의 파일을 백그라운드에서 읽고 쓸 수 있다 | Electron(무겁고 Android 없음), Capacitor(데스크톱 없음), PWA만(폴더 불가) | [ADR-0010](./adr/0010-native-shell.md) |
| **셸은 판정하지 않는다** | 브라우저와 앱이 같은 규칙으로 병합하고, 신뢰 경계가 하나로 남는다 | Rust 쪽 병합·검증 | DESIGN.md 원칙 20 |
| **"파일 하나가 정본"은 동기화 서비스 폴더로** | 서버 운영 없이 무료이고, 파일이 사용자 손에 남는다. 사용자가 이미 쓰는 서비스를 그대로 쓴다 | 직접 만든 파일 전송 | [ADR-0011](./adr/0011-folder-backend.md) |
| **CAS 없는 원격은 루프가 보정하되, 남의 바이트는 지우지 않는다** | 동기화 서비스는 파일을 묻지 않고 바꾼다. 보정이 없으면 잃은 쓰기가 복구되지 않고, 지우는 보정은 데이터 손실이 된다 | 편집이 있을 때만 푸시 | DESIGN.md 원칙 21 |
| **무료 서버는 Cloudflare Worker + Durable Object** | 결제 수단 없이 배포되고, 회수되지 않으며, 강한 일관성이라 CAS가 성립한다 | 무료 VM(회수됨), KV(결과적 일관성), R2(결제 수단 필요) | [backend-capacity.md](./research/backend-capacity.md) |
| **소스 구조는 FSD light** | 새 코드의 자리를 그 코드가 무엇을 아는가로 정한다. import 방향은 스크립트가 강제한다 | 도메인 폴더만 두기, 정통 FSD, 패키지 분할 | [ADR-0013](./adr/0013-fsd-light.md) |
| **앱은 자기 파일에도 저장한다** | 웹뷰의 저장소 정책에 노트를 맡기지 않는다. 두 사본은 병합하지 않고 최신을 쓴다(한 기기의 기록이므로) | IndexedDB만 | [native.md](./design/native.md) |
| **날짜는 텍스트 표기** | Dynalist에서 가져온 날짜가 변환 없이 날짜로 보인다. 스키마와 병합 규칙이 그대로다 | 날짜 필드, 일정 기능 | [ADR-0012](./adr/0012-dates-as-text.md) |
| **빌드는 GitHub의 무료 러너** | 개발 기기에 Rust·Android SDK가 없어도 태그 하나로 네 플랫폼이 나온다. 서명 키는 서드파티 스크립트가 없는 잡에서만 풀린다 | 로컬 빌드 | [native.md](./design/native.md) 「빌드」 |

## 어떻게 검증하나

| 층 | 무엇 |
|---|---|
| 유닛 (Vitest) | 정렬 키, 트리 연산, 병합, 검증, 질의 언어, 날짜, 폴더 백엔드와 푸시 판정 |
| e2e (Playwright, 실제 브라우저) | 편집·IME·드래그, 서식 키보드, 두 기기 동기화, 적대적 서버, 암호, 레퍼런스 서버 프로세스, 2,000줄 성능, 폰 에뮬레이션 |
| 구조 검사 (`npm run check:layers`) | 층·슬라이스 사이의 import 방향 ([ADR-0013](./adr/0013-fsd-light.md)) |
| `folder.rs` 단독 테스트 | 셸의 디스크 작업 전부 (허용 목록 포함) |
| 네이티브 스모크 | **실제 Linux 앱**(tauri-driver)과 **에뮬레이터의 Android APK**를 구동해 입력·IPC·파일·충돌 사본·창 인셋을 본다. macOS·Windows 앱은 실행해서 첫 저장이 로컬 사본에 닿는지까지 본다 |
| 독립 리뷰 | 브랜치 전체를 행동 기준으로 검토해 데이터 손실 경로를 찾는다. 2026-09-29 리뷰가 찾은 것은 ADR-0011 「리뷰 후기」에 있다 |

자동 검증이 닿지 않는 곳도 적어 둔다. macOS·Windows 앱은 실행까지만 확인하고 입력은 구동하지 않으며, 동기화 서비스가 실제로 만드는
충돌 사본의 이름은 실물로만 확인된다(PLANS.md 10번).
