# Phase 19: 모바일 패키징과 고급 확장 - 추후 확장

Stage 3 Future Expansion의 시작점이다. 제품 코어와 배포/sync 경계가 안정된 뒤 진행한다.

### 후보 범위

- Capacitor 기반 iOS/Android 패키징
- 모바일 persistence adapter와 keyboard handling
- graph view 고도화
- aliases, transclusion/embed
- folder/collection, document template
- attachment/image vault
- public share, collaboration, permissions

### 진행 조건

- Stage 1 다중 문서 workspace가 안정되어야 한다.
- Stage 2 계정/sync 제품화가 완료되어야 한다.
- 모바일에서 다중 문서 탐색과 링크 picker가 작은 화면에 맞게 재설계되어야 한다.

### 완료 기준

이 Phase는 아직 구체 구현 범위가 아니라 추후 확장 후보를 보관하는 단계다. 실제 착수 시 모바일 패키징과 고급 지식관리 기능을 별도 Phase로 다시 쪼갠다.
