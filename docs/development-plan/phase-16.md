# Phase 16: 데스크톱 앱과 계정 기능 - 예정

### 목표

웹 버전의 편집 경험이 안정화된 뒤 데스크톱 앱 배포와 계정 기반 사용 흐름을 준비한다. 이 Phase는 아직 가볍게 명시만 하고, 상세 범위는 Phase 15 완료 후 확정한다.

### 후보 범위

- 데스크톱 앱 패키징
- 자동 업데이트 정책
- 로컬 파일/백업 연동
- 계정 생성, 로그인, 로그아웃
- 계정 기반 sync 설정
- 기기 목록과 세션 관리

### 완료 기준

- 데스크톱 앱으로 설치/실행할 수 있다.
- 사용자가 계정을 통해 기기 간 사용 흐름을 시작할 수 있다.
- 모바일 패키징 전에 sync/account 정책이 정리된다.
