# 0010 — 네이티브 앱은 Tauri 2 셸 하나로 만들고, 셸은 판정하지 않는다

- 상태: 승인
- 날짜: 2026-09-29
- 뒤집는 결정: [parity.md](../parity.md) §6 「하나 안 한 것: Tauri」, PLANS.md 「범위에서 뺀 것」의 Tauri 항목

## 맥락

2026-08에는 Tauri를 하지 않기로 했다. PWA가 설치·오프라인·공유 캡처를 이미 하고 있었고, 네이티브
셸이 더 주는 것은 작업 표시줄 아이콘과 전역 단축키 정도라고 보았기 때문이다. 대가는 Rust 툴체인과
플랫폼별 빌드였다.

2026-09-29에 사용자가 방향을 정했다. **데스크톱(macOS 포함)과 Android에 설치되는 앱**이 필요하고,
각 플랫폼에서 로컬로만 써도 되고 서버와 연결해도 되어야 한다. 그리고 동기화의 선택지로 **파일 하나를
정본으로 주고받는 방식**을 열어 두기를 원했다. 이 마지막 요구는 PWA로는 채울 수 없다. 브라우저는
iCloud Drive나 Dropbox 폴더의 파일을 백그라운드에서 읽고 쓰지 못하기 때문이다. 그래서 셸이 더 주는
것이 "아이콘"에서 "디스크에 있는 정본 파일"로 바뀌었고, 이것이 판정을 뒤집은 근거다.

## 결정

1. **Tauri 2 프로젝트 하나(`src-tauri/`)로 macOS·Windows·Linux·Android를 모두 만든다.** 셸은 시스템
   웹뷰(WKWebView, WebView2, WebKitGTK, Android WebView)에 **웹 배포와 같은 정적 빌드**를 띄운다.
   화면·편집·병합 코드는 한 벌이다.
2. **웹 코드는 `@tauri-apps/api` 패키지를 쓰지 않는다.** `withGlobalTauri`가 넣어 주는
   `window.__TAURI__` 전역만 `src/shared/native.ts`에서 읽는다. 브라우저 빌드는 네이티브 코드를 한
   바이트도 싣지 않고, 런타임 의존성 목록(DESIGN.md 원칙 12)도 그대로다. CLI도
   `devDependencies`에 넣지 않고 `npm run tauri`가 `npx`로 받는다. 웹만 만지는 사람의 `npm ci`에
   플랫폼별 바이너리가 끼어들지 않게 하기 위해서다.
3. **셸은 바이트를 옮길 뿐 판정하지 않는다** (DESIGN.md 원칙 20). Rust 쪽 명령은 파일 읽기·조건부
   쓰기, 폴더 고르기, 시스템 브라우저 열기, 창 앞으로 가져오기뿐이다. 파싱·검증·병합은 전부 웹 코드에
   남는다. 그래야 브라우저와 앱이 같은 규칙으로 병합하고, 신뢰 경계(`validate.ts`)가 둘로 갈라지지
   않는다.
4. **빌드는 GitHub의 무료 러너가 한다** (`.github/workflows/native.yml`). 개발자 기기에 Rust와
   Android SDK가 없어도 태그 하나로 설치 파일이 나온다. 아이콘은 `public/icon.svg`에서, Android
   프로젝트는 `tauri.conf.json`에서 매번 생성하고 커밋하지 않는다. 정본을 하나로 두기 위해서다.
5. **PWA는 그대로 둔다.** 설치 없이 여는 경로이고, iOS에서는 유일한 경로다.

## 검토한 대안

- **Electron:** Chromium을 통째로 싣기 때문에 설치 파일이 100MB를 넘고 Android가 없다.
- **Capacitor:** Android는 좋지만 데스크톱이 없다. Electron과 섞으면 셸이 둘이 된다.
- **PWA만 유지:** 폴더 백엔드가 불가능하다. Chromium 계열의 File System Access API는 탭이 열려 있을
  때 사용자의 허락을 매 세션 다시 받아야 하고, Safari·Firefox·Android에는 없다.

## 결과

- 2026-09-29 후기: 셸은 저장할 때마다 앱 데이터 폴더에 워크스페이스 파일도 쓰게 되었고(더 최근의 쪽을
  시작할 때 쓴다), 폴더 명령은 셸이 허용한 폴더에만 닿는다. 상세는
  [native.md](../design/native.md).
- 셸이 주는 것: 디스크의 정본 파일(폴더 백엔드, [ADR-0011](./0011-folder-backend.md)), 전역 단축키
  ⌘⌥O / Ctrl+Alt+O로 창 불러오기, 외부 링크를 시스템 브라우저로 여는 것. 웹뷰 안의 IndexedDB가 브라우저보다 오래
  보존되는지는 플랫폼마다 달라서 확인하지 않았다. 원칙 18의 등급 표시는 셸 안에서도 그대로 동작하고,
  디스크에 확실한 사본을 두고 싶다면 폴더 백엔드를 쓰면 된다.
- 대가: macOS 설치 파일은 서명·공증이 없다(유료 개발자 계정이 필요하다). 처음 열 때 한 번 우클릭 →
  열기가 필요하다. Android APK는 저장소 비밀값의 키로 서명하고, 키가 없으면 매번 새 키로 서명되어
  업데이트 설치가 되지 않는다.
- 셸 안에서는 GitHub 로그인 버튼이 뜨지 않는다. OAuth 콜백이 웹 origin으로 돌아와야 하기 때문이다.
  PAT 붙여넣기는 그대로 동작한다.
- iOS는 범위 밖이다. Tauri가 지원하지만 설치에 유료 개발자 계정이 필요하다.
